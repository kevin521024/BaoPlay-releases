# 饱饱影视

饱饱影视（BaoPlay）是一个 macOS 桌面影视客户端：用你自己准备的订阅源，在一个界面里浏览、搜索、收藏和播放。软件本身不提供任何影视内容。

## 能做什么

- 导入自备的点播与直播订阅，按线路浏览影视墙与详情页；顶栏的「历史」页接着上次的进度继续播，「收藏」页是一面海报墙。
- 聚合搜索：一次搜索当前订阅中的多个来源，结果按线路逐条返回。
- 直播：频道分组、频道搜索、台标与延迟参考；有节目单（EPG）时显示当前与下一档，播放页侧栏可在「频道 / 节目单」之间切换，并支持 ←/→ 换台。
- 播放：默认使用网页播放；系统装有 mpv 或 VLC 时可切换桌面后端，兼容更多格式。
- 播放页侧栏（选集 / 选台）可在左、右之间切换，并记住上次的位置。
- 关闭窗口只隐藏应用，点 Dock 图标或菜单栏图标可恢复；Cmd+Q 或菜单栏「退出」退出。
- 收藏、观看历史、续播进度与搜索历史保存在本机，可分别关闭或清理；历史和收藏都有独立页面，支持单条删除与一键清空。
- 影视墙封面会缓存到本地，切换分类、翻页不会重复下载。

## 下载与安装

到 [Releases](https://github.com/kevin521024/BaoPlay-releases/releases) 页面，按机器架构下载：

| 机器 | 下载 |
|---|---|
| Apple Silicon（M1 / M2 / M3 / M4） | `BaoPlay_<版本>_aarch64.dmg` |
| Intel | `BaoPlay_<版本>_x86_64.dmg` |

安装：打开 dmg，把「饱饱影视」拖进「应用程序」，然后从「应用程序」启动。

不确定自己的架构：打开  菜单 →「关于本机」，看「芯片」一栏；Apple 芯片选 `aarch64`，Intel 选 `x86_64`。

## 第一次打开被 macOS 拦住

当前安装包没有 Apple 开发者签名与公证，第一次打开时系统可能提示「无法验证开发者」。

1. 在「应用程序」里右键「饱饱影视」，选「打开」，再确认一次「打开」；
2. 或者打开 系统设置 → 隐私与安全性，在底部点「仍要打开」。

处理一次之后即可正常双击启动，不需要每次操作。

## 自动更新

应用会读取本仓库的更新清单 `latest.json`，在「设置 → 关于 → 检查更新」中检查新版本：

1. 发现新版本后下载对应架构的更新包；
2. 下载完成后校验签名，校验不通过不会安装；
3. 安装完成后按提示重启应用。

也可以随时到 Releases 页面手动下载 dmg 覆盖安装，本地的订阅、收藏、历史与进度都会保留。
