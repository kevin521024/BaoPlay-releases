# 饱饱影视

饱饱影视是一个 macOS 影视播放器：用自己的点播源与直播源，在一个界面里浏览、搜索、收藏和播放。

## 主要功能

- 点播订阅：导入订阅地址，按当前仓或多仓浏览
- 影视墙与详情页：分类浏览、继续观看、收藏
- 聚合搜索：一次搜索多个来源
- 直播：支持 M3U 与内嵌直播源，带频道分组、频道搜索和延迟显示
- 播放后端：内置网页播放，也可切换系统的 mpv / VLC
- 快捷键与全屏播放，播放进度、历史与收藏自动保存
- 应用内检查更新，签名校验通过后直接下载安装

## 下载

到 [Releases](https://github.com/kevin521024/BaoPlay-releases/releases) 页面，下载最新版本的
`BaoPlay_<版本>_aarch64.dmg`（适用于 Apple Silicon）。

安装：打开 dmg，把「饱饱影视」拖进「应用程序」，然后从「应用程序」启动。
Windows 版本尚未验证，暂不提供。

## 第一次打开被 macOS 拦住

当前安装包没有 Apple 开发者签名和公证，第一次打开时系统可能提示“无法验证开发者”。

1. 在「应用程序」里右键「饱饱影视」，选「打开」，再确认一次「打开」；
2. 或者打开 系统设置 → 隐私与安全性，在底部点「仍要打开」。

处理一次之后就可以正常双击启动，不需要每次都操作。

## 自动更新

打开 设置 → 关于 → 检查更新，会自动下载并安装新版本，安装完点「立即重启」即可。
也可以随时回到 Releases 页面手动下载安装包覆盖安装，数据会保留。

## 说明

本仓库只存放安装包和更新清单，不提供任何影视内容；播放的内容来自你自己配置的订阅源。
